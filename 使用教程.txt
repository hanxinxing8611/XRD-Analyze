XRD Analyze 使用教程（便携版）
================================

一、启动（两种方式任选）
  方式1（推荐）：直接双击文件夹里的 index.html
  方式2：双击“启动 XRD Analyze.bat”（会起本地服务并自动打开浏览器，
         关闭黑色窗口即停止服务；此方式会读取“标准样”文件夹里的 .uxd 标准文件）

二、界面说明
  顶部：
    - 产品类型下拉框（选择要分析的产品）
    - 导入标准样品（一般不用管，选产品后自动带入；也可手动上传替换）
    - 导入测试样品（上传你的 XRD 数据）
    - “分析”按钮
    - 导出按钮：PNG / PDF（分析完成后可用）
  谱图区图例：
    - 蓝色虚线 = 理论峰位
    - 蓝色实线 = 标准样品谱图
    - 绿色实线 = 测试样品谱图
  谱图下方为分析结果分区（可点击标题折叠/展开）：
    杂质相综合判定 / 杂质峰详细匹配 / 衍射峰对比 / 结晶度分析 /
    晶格参数精修 / 物相半定量分析(RIR) / 峰形分析与晶粒尺寸 /
    数据质量评估 / 测量不确定度评估

三、使用步骤
  第1步：选择产品类型
    在下拉框选择你的产品（CsPbBr3 / CsPbI3 / FAPbBr3 / δ-FAPbI3 /
    α-FAPbI3 / MAPbBr3 / MAPbI3 / C60）。
    选择后自动加载：蓝色虚线=该产品的理论峰位，蓝色实线=标准样品谱图。

  第2步：导入测试样品
    点击“导入测试样品”区域，选择你的 XRD 数据文件
    （支持 .uxd / .txt / .csv / .xy / .dat，可多选）。
    也可以直接把文件拖进该区域。

  第3步：点击“分析”
    系统自动完成：预处理（平滑/基线校正/Kα2剥离）→ 峰检测 →
    系统偏移校正 → 主相掩膜 → 杂质峰识别 → 杂质相判定评分。

  第4步：查看结果
    谱图：三条线对比（理论峰位 / 标准样品 / 测试样品），可缩放查看。
    杂质相综合判定：列出识别出的杂质相、化学式、置信度、匹配峰数、
    强峰覆盖率、占杂质强度比、相对主相强度。
    杂质峰详细匹配：每个杂质峰的 2θ、强度、可能成分。
    其它分区：衍射峰对比、结晶度、晶格参数精修、RIR 半定量、
    峰形与晶粒尺寸、数据质量、不确定度。

  第5步：导出报告
    点击“PDF”导出完整检测报告（含谱图、峰位对比表、杂质判定、结论），
    点击“PNG”导出当前谱图图片。

四、手动替换标准样品（可选）
  在“导入标准样品”区域上传你的标准谱图文件，即可用它替换自动带入的
  标准样品进行对比（自动带入的标准仍以蓝虚线理论峰位为准）。

五、常见问题
  Q1 产品列表为空 / 数据像旧的？
     → 按 Ctrl+F5 强制刷新；确认页面顶部显示“标准数据版本: 2026-08-06”。
  Q2 双击 index.html 后“导入测试样品”无法读取标准样文件夹？
     → 直接双击 index.html 使用的是程序内嵌标准数据（与标准文件夹一致），
       功能完全相同；如需读取外部 .uxd 标准文件，请用“启动 XRD Analyze.bat”。
  Q3 文件格式支持？
     → .uxd / .txt / .csv / .xy / .dat（两列：2θ 与强度）。
  Q4 双击 bat 没反应？
     → 右键 → 以管理员身份运行；或改用直接双击 index.html。
  Q5 端口被占用？
     → 关闭占用 8765-8800 端口的程序后重试。

六、说明
  - 完全离线运行，不联网、不上传任何数据。
  - “标准样”文件夹内为各产品标准谱图，一般无需改动。
  - 系统要求 Windows 10/11。
